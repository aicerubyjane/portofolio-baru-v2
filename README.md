# Aicerubyjane — private computer-world preview

Not deployed. Public repository and production services are unchanged.

## Run
Extract the ZIP and run `python3 -m http.server 8000` in its folder. Open http://localhost:8000. ES modules require HTTP, not file://. No install/build is required; Three.js, Commissioner and images are bundled. Runtime makes no external requests; source/contact links open only when selected.

## Explore
Scroll through five project computers, About and Contact. Camera depth changes within a cool-white Three.js studio with satin silver hardware, soft blue accents, beveled edges, contact shadows and clear foregrounds. Each station synchronizes its visible copy and its computer atomically, preventing a previous project from appearing behind the next title. Drag for a bounded alternate viewpoint, turn computers, inspect full source captures in dialogs, or use numbered links and keyboard navigation. Escape closes dialogs and returns focus; explicit Tab wrapping keeps focus inside. Reduced motion removes easing/continuous animation. List view and WebGL-failure fallback retain all projects and source links.
